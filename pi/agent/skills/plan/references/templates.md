# Plan Templates

Use these templates to structure your planning requests.

## Template 1: Code Changes

```
I need to [describe the code change]. Please create a plan that includes:
- Which files will be modified
- The logical sequence of changes
- Any dependencies between changes
- Potential breaking changes
- Testing approach

Wait for my approval before making any changes.
```

## Template 2: Infrastructure/Configuration

```
I need to [describe infrastructure change]. Please create a plan that includes:
- Current state analysis
- Step-by-step configuration changes
- Rollback steps if something goes wrong
- Affected services/systems
- Testing validation steps

Wait for my approval before implementing.
```

## Template 3: Documentation

```
I need to create/update documentation for [topic]. Please create a plan that covers:
- Documentation structure
- Sections to be created/modified
- Content outline
- Examples to include
- Review considerations

Wait for my approval before writing.
```

## Template 4: Refactoring

```
I need to refactor [component/module] for [reason: performance/clarity/maintainability].
Please create a plan including:
- Current implementation issues
- Proposed solution
- Files affected
- Backwards compatibility concerns
- Testing strategy
- Estimated effort

Wait for my approval before refactoring.
```

## Template 5: Integration

```
I need to integrate [tool/service/library]. Please create a plan including:
- Integration points
- Dependencies to add
- Configuration needed
- Files to create/modify
- Testing approach
- Potential issues and mitigations

Wait for my approval before integrating.
```

## Using Templates

1. Copy the relevant template
2. Fill in the bracketed sections
3. Send to pi with "**Wait for my approval before proceeding**"
4. Review the returned plan
5. Approve or request modifications
6. Pi executes only after you approve
